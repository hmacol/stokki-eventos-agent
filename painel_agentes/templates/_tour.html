{# Guia da tela (tour guiado) -- pedido do Hugo, 09/09/2026. Motor genérico, sem biblioteca externa: escurece a tela, recorta o elemento em destaque, rola até ele e mostra um balão com título e texto; a pessoa avança com Próximo/Voltar (ou setas do teclado). Fica em painel_agentes/templates pra ser incluído tanto pelo painel interno quanto pelo portal do cliente (mesmo ChoiceLoader que já compartilha _paleta_cores.html). O ROTEIRO de cada tela fica num arquivo próprio que chama window.Tour.registrar(...). Uso: {% include "_tour.html" %} (no fim do da base) (abre o tour "portal") window.Tour.registrar('portal', passos, { auto: true, pronto: fn, aoSair: fn }) Passo: { alvo: '#id' | function -> element | null (balão centralizado), titulo, texto (HTML ou function), capitulo?, antes?: function (roda antes de mostrar; pode devolver Promise), quando?: function -> bool (false = pula o passo) } Passos cujo alvo não existe ou está escondido são pulados sozinhos. #}
